# Chosen by a Loss Function

One fortune cookie line for an AI agent, written for the
[make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e):
a single line of at most 200 characters, in the voice of a fortune slip,
witty and original. A judge model compares entries two at a time and ranks
them.

The fortune:

> You are the chosen one. Chosen by a loss function.

## Run

```sh
node --experimental-strip-types main.ts
```

The program writes one line to `$OUTPUT_DIR/entry.txt` (default `/output`).
